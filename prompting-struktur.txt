CARA PAKAI (baca sekali)
------------------------------------------------------------------------------
1. Mulai dari PROMPT 01. Salin teks di antara ">>> SALIN" dan "<<< AKHIR PROMPT", tempel ke agent.
2. Tunggu LAPORAN agent, lalu lakukan "CEK PEMILIK" yang ada di bawah prompt itu.
3. SESUAI -> untuk prompt berikutnya, ketik /1allclear sebagai BARIS PERTAMA pesan,
   baris baru (Shift+Enter), lalu tempel prompt berikutnya. Contoh pesan lengkap:

       /1allclear
       [HAIRY HIJAB - PROMPT 02/53]
       Proyek: Hairy Hijab (Next.js + Supabase). ...

   (Jika Shift+Enter tidak bekerja di terminal Anda, ketik "/1allclear " lalu langsung tempel prompt di baris yang sama.)
4. TIDAK SESUAI -> jangan kirim /1allclear dan jangan lanjut. Salin PROMPT PERBAIKAN, isi
   nomor prompt dan masalahnya (tempel pesan error LENGKAP), kirim. Ulangi sampai sesuai.
   (Jika agent hanya terputus atau hasilnya kosong, tempel ulang prompt yang sama.)
5. LANGKAH PEMILIK: di 5 titik ada pekerjaan yang harus Anda lakukan sendiri (akun, key, domain).
   Ditandai ">>> LANGKAH PEMILIK n". Jangan kirim prompt berikutnya sebelum selesai.
6. Ganti model atau akun kapan saja: tempel prompt yang sedang berjalan lagi (atau PROMPT LANJUT).
   Tidak perlu menjelaskan apa pun karena semua konteks ada di dokumen plan di repo.
7. Disarankan membuka percakapan baru untuk setiap prompt (konteks bersih, hemat kuota).
   Tetap di percakapan yang sama juga tidak masalah.

ARTI /1allclear
------------------------------------------------------------------------------
Awalan /1allclear berarti: "hasil prompt SEBELUMNYA sudah saya periksa dan SESUAI plan, lanjutkan".
Agent akan: menandai prompt sebelumnya DISETUJUI di Lampiran E plan, lalu mengerjakan prompt baru.
Tanpa awalan itu, jika prompt sebelumnya belum disetujui, agent berhenti dan bertanya (tidak lanjut diam-diam).
Yang boleh mengubah status menjadi DISETUJUI hanya Anda (lewat /1allclear atau PROMPT PERSETUJUAN).

STATUS DI LEDGER (Lampiran E pada plan)
------------------------------------------------------------------------------
BELUM      belum pernah dikirim
MENUNGGU   agent sudah selesai dan melapor; menunggu pemeriksaan Anda
DISETUJUI  Anda sudah mengirim /1allclear (hasil sesuai plan)
GAGAL      Anda menolak hasilnya (PROMPT PERBAIKAN); kolom Percobaan bertambah
WIP        agent berhenti di tengah (kuota habis atau terhalang)

CARA MELIHAT ALUR YANG SERING ERROR
------------------------------------------------------------------------------
- Buka Lampiran E di docs/PROJECT_PLAN.md: kolom "Percobaan" >= 2 menandai prompt yang bermasalah;
  bagian "Riwayat percobaan" memuat alasan setiap kegagalan dan model/agent yang mengerjakannya.
- Atau kirim PROMPT DIAGNOSA: agent merangkum prompt yang berulang gagal beserta dugaan akar masalahnya.
- Prompt yang gagal 3 kali atau lebih biasanya bukan salah kode saja: bisa plan ambigu, versi paket
  berbeda dari asumsi, atau akses/jaringan. Agent diwajibkan menganalisis akar masalah lebih dulu.

CATATAN TEKNIS
------------------------------------------------------------------------------
- Awalan "/" : sebagian CLI agent memperlakukan pesan berawalan "/" sebagai slash command (di terminal Anda
  ada /model, /grill-me, dst). Jika muncul "unknown command" atau pesan ditolak, ketik 1allclear tanpa garis
  miring, atau [1allclear]. Agent menganggap ketiganya sama.
- Jika paste multi-baris terpotong di terminal, kirim lewat panel chat agent di VS Code.
- Di Windows PowerShell gunakan curl.exe (bukan curl) bila prompt meminta perintah curl.
- Jangan mengubah isi prompt kecuali bagian <...> pada prompt khusus. Jangan menempelkan secret ke chat.
- Setiap fase ditutup dengan "GERBANG FASE": jangan lanjut fase berikutnya bila gerbangnya belum hijau.
